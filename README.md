# Proyecto-Gestion-Documental-Movil-CMQ
Proyecto para la gestión de datos de funcionarios del área de la salud
La gestión documental de funcionarios del Área Salud de la Corporación Municipal
de Quilpué se realiza de forma dispersa (Excel, correo, carpetas), sin
trazabilidad ni control de acceso uniforme, lo que genera riesgos de seguridad
y pérdida de información en un ámbito sensible de datos personales de salud.

## Objetivo general
Desarrollar una app móvil (MVP) que centralice la gestión documental de
funcionarios, con control de acceso por rol, trazabilidad de acciones y
diseño de integración con SharePoint/M365.

## Tecnologías
- Android Studio + Kotlin
- Jetpack Compose
- Arquitectura MVVM
- Persistencia local
